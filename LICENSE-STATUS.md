No new open-source license is chosen by this handoff. **Do not assume that public visibility on GitHub grants reuse, distribution or relicensing rights.**

The archived PRSL Lab v0.2.0 README says the new laboratory code is project working material, disclaims transfer of upstream ownership, and instructs the project to choose a license before public distribution. The existing fan-patch and launcher projects may carry independent notices and GPL obligations; these do **not** automatically grant rights to commercial MOO2 content.

Before enabling redistribution or seeking upstream contributions:

1. Confirm authorship and provenance of each imported file.
2. Review third-party licenses for copied snippets, helper code and dependencies.
3. Select a license compatible with any actually reused code and intended upstream integration; record it in a real `LICENSE` file.
4. Keep source game binaries, copyrighted LBX assets and user-supplied patched executables out of the repository/release unless explicit redistribution rights are established.
5. Preserve notices in imported source, including any headers provided by prior research.

This is a tracking document, **not a substitute software license**.
